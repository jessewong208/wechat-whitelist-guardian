# 微信公众号 API IP 白名单参考

## 使用前必读

### 环境准备：开通 WorkBuddy 浏览器操控

本 skill 依赖浏览器自动化，首次使用前在 WorkBuddy 里开启：**设置 → 智能体 → 浏览器操控（Beta）**，打开「让 WorkBuddy 控制浏览器」开关；再给常用浏览器安装对应的 **WorkBuddy Chrome / Edge / QQ 浏览器扩展程序**（设置页点「前往安装」，装完工具栏图标显示「已连接」）。扩展商店访问不了时用同页的「手动安装」，在浏览器扩展页开启「开发者模式」拖入插件文件夹。未开通时脚本无法启动浏览器、抓不到二维码。

### 本地弹窗 vs 远程推送（两种扫码场景）

- **`local` 本地弹窗（默认）**：二维码出现在**当前电脑屏幕**上，省去自己开网页找入口登录的麻烦，你就在电脑旁直接扫屏幕。
- **`wecom` / `feishu` / `dingtalk` 远程推送**：二维码发到**另一台电脑**（如公司 PC）上的企微/飞书/钉钉客户端，适合你不在本地电脑旁、但在那台电脑前用手机摄像头扫码，远程完成微信开发者平台登录和白名单修改。远端电脑需开着对应 IM 且你能看到屏幕。

**注意**：微信扫码只认手机摄像头实时扫描屏幕，相册/长按识别无效。远程推送不等于"手机收到图就能扫"——扫的仍是**显示二维码的那块电脑屏幕**。

## 校验机制

- 所有 `cgi-bin/*` 接口（token / draft / freepublish 等）都校验请求来源 IP
- 校验发生在 AppID/AppSecret 校验之前——IP 不对时第一个接口就挂
- 不在白名单 → `{"errcode":40164,"errmsg":"invalid ip x.x.x.x, not in whitelist"}`

## 配置规则

- 支持单个 IP：`123.45.67.89`
- 支持 CIDR：`123.45.67.0/24` 或 `123.45.67.1/24`
- 小程序支持通配 `123.45.67.*`，公众号/服务号不支持，只认 CIDR
- 最多 10 个条目（视账号类型），不支持 `IP:端口` 格式
- 仅 IPv4；修改后 3-10 分钟生效

## 修改路径（重要：入口已迁移）

**2025-12 起**，公众号「API IP白名单」从 mp.weixin.qq.com 迁移到微信开发者平台：

微信开发者平台 developers.weixin.qq.com → 控制台 → 我的业务 → 公众号/服务号 → 基础信息 → 开发密钥 → API IP白名单 → 编辑 → 填入 IP → 确定 → **管理员扫码授权**（手机摄像头扫电脑屏幕）→ 生效。

- 直达 URL（需已登录态，未登录报「请重新登录」）：
  `https://developers.weixin.qq.com/console/product/mp/<AppID>?tab1=basicInfo&tab2=dev`
- 老入口（mp.weixin.qq.com → 设置与开发 → 基本配置 → IP白名单）已无该项，别再翻。

本 skill 的 `apply_whitelist.js` 已把「填 IP → 确定 → 弹授权码 → 扫码 → 回读」做成闭环。

## 动态 IP 的三种解法

1. **CIDR 网段（零成本，先试）**：若历次 IP 都落在同一个 /24 段，直接填网段。用 `ip_guard.py history` 判断。脚本会在检测到至少 3 个样本后给出 CIDR 建议。
2. **固定出口代理（彻底，需云资源）**：用云函数/云服务器做反向代理，白名单只填云服务的固定出口 IP。阿里云函数计算有免费额度且出口 IP 段固定。Cloudflare Worker 不适用（出口 IP 是全球边缘节点，无法全量加白名单）。
3. **半自动（本 skill）**：检测变化 + 准备好新 IP + 扫码登录 + 自动填 IP + 授权码 + 回读确认。

## 二维码推送渠道说明

`config.json` 的 `notify_channel` 决定二维码往哪推：`local`（默认，电脑弹窗扫屏幕）/ `wecom`（企微）/ `feishu`（飞书）/ `dingtalk`（钉钉）/ `all`（全部已配置渠道）。个人微信无推送 API，用 `local` 扫屏幕即可。

钉钉（`dingtalk_mode`）两种模式任选：
- **webhook（默认，推荐）**：钉钉群 → 设置 → 智能群助手 → 添加"自定义机器人" → 复制 Webhook 地址填 `dingtalk_webhook`。若机器人设了"加签"，把 secret 填 `dingtalk_secret`。零安装、无需加组织。
- **cli**：适合已加入组织且有 CLI 权限的用户。装 `dingtalk-workspace-cli` + `dws auth login`，填 `dingtalk_target_type`/`dingtalk_target_id`。命令可用 `dingtalk_*_cmd` 模板覆盖。

## 排查清单

- 报 40164 → 先跑 `python ip_guard.py show` 看当前出口 IP
- 填进白名单的必须是**公网 IP**，不是 `192.168.x.x` / `10.x.x.x`
- 微信报错里出现 `::ffff:x.x.x.x` 时，填 IPv4 那段即可
- 改完等 3-5 分钟再重试，不要连续刷新
- 扫码报「系统错误」→ 授权窗口已失效（脚本进程退出或码过期），重新执行并换新输出文件名
- 开发者平台提示「请重新登录」→ 先跑 `dev_login.js` 重新扫码登录
